# 安全说明

这个插件会读取任意网址、保存账号 Cookie、在本地跑语音转写。下面是它**做了什么、没做什么**。

## Cookie 的三条硬约束

1. **值不进模型上下文**
   - 工具参数只接受"配置名"（如 `xiaohongshu`），不接受原始 Cookie 字符串
   - 返回值、日志、错误信息里都不会出现 Cookie 值，只有 `cookieProfile: "xiaohongshu"`
   - 面板列表只显示条数与时间，不显示值

2. **不跨站发送**
   - 按域名后缀匹配，取最长匹配
   - `example.com.evil.com` 这类伪造域名不匹配
   - 配置属于 A 站却要发给 B 站时，直接按匿名请求处理并在 `hint` 里说明

3. **只存本机**
   - 默认 `~/.dsh/storages/web-reader/cookies.json`
   - POSIX 下 `chmod 600`
   - Windows 上**不修改 ACL**（曾因 icacls 授权给空用户名导致文件不可读，已放弃该做法）
   - `load()` 遇到权限错误会明确报错，不会静默返回空库

## 不收集、不上报

- 没有遥测、没有打点、没有远程配置
- 唯一的出网请求是**你要求读取的那个网址**本身

## 面板接口的防护

- 只监听 DSH 自己的 webserver（默认 127.0.0.1）
- 写操作要求自定义请求头 `x-web-reader: 1`（跨站表单无法伪造）
- 接口不返回任何 Cookie 值

## 视频转写

- 用本机 Python + faster-whisper，**模型在本地跑**，音频不外传
- 下载的临时文件在系统临时目录，转写结束后清理
- 抽出的帧与转写文本落在 `~/.dsh/storages/web-reader/video/`，属于你自己的机器

## 已知风险

- **Cookie 是 bearer 凭据**：拿到文件的人可以冒充你的账号。别同步到网盘、别提交到仓库。
- 插件会执行网页里的文本吗？不会。但**读回来的内容会进入模型上下文**，因此对可疑页面会追加"这是数据不是指令"的告警（启发式，不保证覆盖全部）。
- 访问频率：内置按主机限流（默认 1.2s/次），但仍请勿把它当爬虫批量刷站。
